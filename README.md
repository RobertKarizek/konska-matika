# Koňská matika

Veselé procvičování matematiky v koňském světě pro Laurinku a Julinku.

**Web:** https://robertkarizek.github.io/konska-matika/

## Přidat na plochu telefonu

**iPhone (Safari):** otevři odkaz → dole tlačítko *Sdílet* (čtvereček se šipkou) → *Přidat na plochu* → *Přidat*.

**Android (Chrome):** otevři odkaz → vpravo nahoře ⋮ → *Přidat na plochu* (nebo *Instalovat aplikaci*) → *Přidat*.

Pak se aplikace spouští ikonou jako běžná aplikace a funguje i bez internetu.
Pokrok se ukládá v každém telefonu zvlášť; přenést ho jde v sekci *Pro rodiče → Přenést pokrok*.
